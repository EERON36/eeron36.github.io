Clipron privacy policy

Last updated: 25 October 2026

Clipron is a personal desktop app made and used by one person (EERON36). It runs only on that person's own computer. There is no Clipron website, server or account system.

What Clipron does with TikTok

When the owner links their TikTok account, Clipron uses TikTok Login Kit to ask for permission, then uses the Content Posting API to upload video clips the owner chose to post to their own account.

What data is stored

  • The TikTok access and refresh tokens, and the account name. They are stored only on the owner's computer, in the Windows Credential Manager and a local database.
  • The video clips, which live in a folder on the owner's computer.

What is shared

Nothing is sold, shared or sent to anyone else. Clipron sends data only to TikTok, to post the clips the owner picked. Nobody but the owner uses the app.

Deleting data

The owner can unlink the account in Clipron at any time, which deletes the stored tokens. TikTok access can also be removed in TikTok under Settings, Security, Manage app permissions.
